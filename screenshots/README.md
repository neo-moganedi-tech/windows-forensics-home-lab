## Evidence Handling

Screenshots are included to support the observations documented in the investigation report

The screenshots should reflect actual lab activity. No screenshots or results should be fabricated or presented as verified when they have not been observed

Before publishing, review each screenshot for sensitive information, including usernames, IP addresses, personal file paths, and other system details that do not need to be public

Raw Windows Security event exports and other potentially sensitive forensic evidence should remain outside the public repository unless appropriately reviewed and sanitised
